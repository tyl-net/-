01 / FOUNDATIONS

三层令牌体系

全部设计取值收敛到唯一真源 tokens.css。产品样式表与规范站本身都只引用 var()， 源码中不再出现任何裸色值、裸字号、裸间距 —— 由 test/design-lint.js 自动断言。

Tier 1

基础层 Primitive

与业务无关的原始色板与刻度：teal / slate / red … 色阶，字号、间距、圆角、阴影刻度。

Tier 2

语义层 Semantic

描述“用途”的角色变量，如 --color-action-primary。产品代码只应引用这一层。

→
Tier 3

组件层 Component

组件专属别名，如 --button-primary-bg。改动一处即全局生效，便于单点微调。

体系现状

02 / COLOR

色彩

品牌青绿取自校园集市既有配色，向两端扩展为完整色阶。基础色板供语义层挑选；产品代码使用语义色， 因此换肤只需改语义层的指向。点击任意色块可复制令牌名。

基础色板 · 主色（青绿）

品牌主色 --teal-500 仅作标识与装饰；承载白色文字的动作底色使用 --teal-600，以满足 AA 对比度。

基础色板 · 中性（灰蓝）

文本、边框、背景的骨架色阶。

基础色板 · 功能色

每族色阶含“浅底 bg / 边框 border / 前景 fg / 实底 action”四种角色，语义层按角色取用。

表达色 · 品类封面

仅用于商品品类封面与头像的渐变，不作 UI 语义色。

语义色 · 产品代码唯一入口

卡片下方依次为：令牌名 / 解析后的最终色值 / 引用次数。带虚线标注的在当前产品中为预留。

09 / ACCESSIBILITY

以 WCAG 2.1 AA 为基线：正文对比度 ≥ 4.5:1，大号文本与图形边界 ≥ 3:1。 组合由 test/contrast-audit.js 按相对亮度公式实算，结果直接驱动下方渲染。

焦点可见性

所有可聚焦元素在键盘导航下必须显示焦点环，且焦点环与背景对比 ≥ 3:1。

触控与动态

  • 可点击元素最小高度 30px，移动端主操作区 ≥ 44px
  • 重要操作提供二次确认，破坏性操作使用 --button-danger-bg 区分语义
  • 动效时长 ≤ 300ms，不依赖动画传达关键信息
  • 文本在 200% 缩放下不出现横向滚动（见 10 响应式）
